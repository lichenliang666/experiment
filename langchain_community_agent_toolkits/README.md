
# 过程记录

参考文档：<https://python.langchain.ac.cn/docs/integrations/tools/filesystem/>

## 项目创过程

1. 使用 uv 创建名为 langchain_community_agent_toolkits 的项目:

  ```cmd
  uv init langchain_community_agent_toolkits
  ```

1. 进入创建的项目目录：

  ```cmd
  cd langchain_community_agent_toolkits
  ```

1. 激活环境：

  ```cmd
  .venv\Scripts\activate
  ```

1. 安装依赖：

```cmd
uv add langchain-community
```

## 项目环境搭建

创建虚拟环境并安装依赖

```cmd
uv sync
```
